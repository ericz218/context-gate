# 订阅额度

控制台左侧“订阅额度”集中显示Codex与Claude Code的5小时、每周额度和重置时间。直接读取平台额度，不调用模型、不启动子agent、不购买额度、不消耗重置券。

间隔从短到长：实时（每5秒刷新）、15秒、30秒、1分钟、3分钟、5分钟、10分钟、30分钟。每个平台独立开启、选择间隔和直接输入1至100的剩余百分比门槛，然后保存。失败时保留上次成功数据，并显示错误与时间；缺失窗口不会当零用量。429和连续错误自动延长重试间隔。

后台检查在控制台服务运行期间继续，关闭窗口不会停止；电脑睡眠时暂停。配置在系统状态目录quota-settings.json，权限0600，不保存凭据。现有原生QuotaGuard的Codex设置已导入，避免两份重复检查。

Codex使用本机CLI的account/rateLimits/read。Claude读取Keychain的Claude Code订阅登录，只向官方api.anthropic.com的/api/oauth/usage发送GET；不跟随重定向，不使用环境代理，令牌不返回浏览器、不写日志。登录过期需在Claude Code完成原生登录再刷新，本轮实际响应为401，界面显示过期。

“报警后停止所有本机会话”默认关闭，与通知开关独立。启用后任一平台触发门槛，会尝试停止两平台本机任务：已连接Codex桌面活跃turn用精确owner及expectedTurnId中断并核验终态；控制台任务及群聊队列复用原停止接口；精确识别Claude CLI后发送SIGINT，仍存活时不冒称远端已经停止。

停止结果逐项显示，覆盖不完整时不报“全部停止”。Codex桌面IPC是内部协议，当前仅允许研究过的build20156；升级或协议不匹配时安全拒绝。不能保证未连接CLI、云端或远程会话、未来预约全部停止，也不会永久禁止长期goal或自动化新建下一轮。持续低额度时，至少间隔30秒重试停止当前新任务。

系统后台通知需要macOS允许；浏览器通知为额外选项，仅页面在线且授权时有效。

验证包括额度解析、缺失值和边界、设置权限与保存、错误退避、停止独立通知、持续低额重试、假socket的精确取消/终态/任务race/未知协议拒绝、进程身份及控制台队列mock。浏览器输入/排序/持久化/校验/布局与正式原生窗口已检查。真实用户任务未用于停止测试。

停止和系统通知使用独立的串行后台动作线程，额度读取不会等待停止扫描；动作执行前重新检查账号、门槛和开关，账号切换前排队的动作及旧停止结果会丢弃。关闭服务时丢弃未开始的动作；已经开始的停止只允许完成其现有有界核验，不能撤回已经发出的中断。Protection 的暂停和恢复串行协调，外部调用不持有额度状态锁。

冷启动发现按最新线程优先，每批最多4个独立只读IPC连接并行探测，保持协议build20156安全校验。扫描预算限制新批次提交；已开始的批次与精确停止核验按各自超时完成并关闭连接。仅明确的no-client-found视为无主；App回复timeout以及传输超时都表示未核实，短暂缓存5分钟且持续报告覆盖不完整，新线程事件立即重探。明确无主缓存最多30分钟，既有窗口没有新事件时可能等TTL到期才发现。并发改善冷启动效率，但不能宣称未核实线程已覆盖。

账号标签为空或读取异常时等待20毫秒重读一次，确认登出仍立即清卡。成功送出的系统通知按账号、额度bucket、窗口和重置时间记录到权限0600的quota-notices.json，重启后同一低额度窗口不重复通知；恢复健康的真实读取或关闭通知会清除相应去重记录。停止重试不读取该通知记录，重启后及持续低额度仍可尝试停止新任务。真实用户活动会话完整停止链路仍为UNVERIFIED。

额度响应的usage_sync仅提供本地导入器最近启动/完成时间、下次计划时间、导入及跳过数量与固定错误类别。缺失或格式不合法返回空状态，不以文件更新时间冒称同步完成，也不由额度接口触发导入。窗口本地用量仍严格匹配同账号与实际额度窗口。
